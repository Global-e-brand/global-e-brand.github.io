What the Pinterest integration does

When a GEB user connects their own Pinterest business account, GEB performs only the actions needed to deliver the scheduling and reporting features the user asked for:

1. Confirm the connection

Reads basic account information (account name, account ID, list of boards owned by the user) so the user can choose which board to publish to.

2. Schedule and publish Pins

Creates Pins on boards the user owns, using image and caption content the user has uploaded inside GEB. Publishing happens at the date and time the user scheduled.

3. Show performance back to the user

Fetches Pin performance metrics (impressions, saves, outbound clicks) for Pins GEB published, so the user can review results inside the GEB dashboard.

What the integration does NOT do

  • It does not browse, scrape, or collect data about other Pinterest users.
  • It does not post to accounts the user does not own.
  • It does not sell, share, or transfer Pinterest data to any third party.
